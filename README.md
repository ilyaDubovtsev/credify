# Credify

MVP веб-приложения для сравнения обычного и досрочного графика погашения
аннуитетного кредита.

## Что уже умеет

- считает аннуитетный график;
- моделирует регулярный досрочный платёж;
- сравнивает уменьшение срока и уменьшение платежа;
- показывает экономию на процентах и новый срок;
- возвращает подробный график платежей через API и интерфейс.

## Запуск через Docker

Нужен только Docker Desktop:

```bash
docker compose up --build
```

После сборки открыть <http://localhost:3000>. Остановка: `Ctrl+C`, затем
`docker compose down`.

## Локальная разработка

Backend:

```bash
dotnet run --project src/Credify.Api --urls http://localhost:5080
```

Frontend требует Node.js 22+:

```bash
cd frontend
npm install
npm run dev
```

Тесты:

```bash
dotnet test Credify.sln
```

## Допущения MVP

- кредит аннуитетный, ставка фиксированная;
- проценты начисляются помесячно: годовая ставка / 12;
- досрочный платёж вносится вместе с регулярным;
- комиссий, страховки, выходных и банковских правил переноса дат нет;
- деньги округляются до копеек после каждой операции;
- результат ориентировочный и не является финансовой рекомендацией.

Следующий продуктовый шаг — добавить разовые досрочные платежи и сравнение
обеих стратегий на одном экране.
