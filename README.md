# Credify

MVP веб-приложения для сравнения обычного и досрочного графика погашения
аннуитетного кредита.

## Что уже умеет

- считает аннуитетный график;
- моделирует регулярный досрочный платёж;
- учитывает несколько разовых платежей по датам;
- одновременно сравнивает уменьшение срока и уменьшение платежа;
- показывает экономию на процентах и новый срок;
- рекомендует самый выгодный сценарий и показывает динамику остатка долга;
- сохраняет введённый сценарий в браузере;
- рассчитывает безопасный разовый платёж с сохранением финансовой подушки;
- возвращает подробный график платежей через API и интерфейс.

## Запуск через Docker

Нужен только Docker Desktop:

```bash
docker compose up --build
```

После сборки открыть <http://localhost:3000>. Остановка: `Ctrl+C`, затем
`docker compose down`.

## Локальная разработка

Backend:

```bash
dotnet run --project src/Credify.Api --urls http://localhost:5080
```

Frontend требует Node.js 22+:

```bash
cd frontend
npm install
npm run dev
```

Тесты:

```bash
dotnet test Credify.sln
```

## Production

Production-конфигурация запускает Caddy с автоматическим HTTPS и не публикует
frontend или API напрямую:

```bash
docker compose -f compose.prod.yaml up -d --build
```

Приложение доступно по адресу <https://credify.dubovtsev.com>. Сертификаты
хранятся в Docker volume `caddy_data` и продлеваются автоматически.

На production-сервере systemd-таймер `credify-deploy.timer` проверяет ветку
`main` каждые пять минут и разворачивает новый commit. Таймер
`credify-health.timer` проверяет публичный health endpoint каждые две минуты и
перезапускает контейнеры при сбое.

## Допущения MVP

- кредит аннуитетный, ставка фиксированная;
- проценты начисляются помесячно: годовая ставка / 12;
- досрочный платёж вносится вместе с регулярным;
- разовый платёж относится к плановому платежу того же календарного месяца;
- комиссий, страховки, выходных и банковских правил переноса дат нет;
- деньги округляются до копеек после каждой операции;
- результат ориентировочный и не является финансовой рекомендацией.

Следующий продуктовый шаг — учитывать переменный ежемесячный бюджет и
неравномерные доходы, чтобы строить гибкий план на несколько месяцев вперёд.
